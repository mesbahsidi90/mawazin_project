# موازين — منصة تقليل هدر المطابخ

نموذج عربي متجاوب يربط ثلاث واجهات في رحلة واحدة:

- تطبيق عامل لتسجيل وزن الهدر وتصنيفه.
- لوحة مدير تعرض الوزن والتكلفة ومصادر الهدر والتوصيات.
- محاكي ميزان لاختبار الاتصال وثبات القراءة والحمولة.

## تحديث محطة المطبخ

- رحلة العامل: الصنف ← المصدر ← الوزن والتأكيد، والإدارة خارج شاشة التسجيل (فصل واجهات فقط وليس نظام صلاحيات).
- إدارة 100 صنف كحد أقصى: الاسم والتكلفة وصورة تمثيلية أو رفع صورة خاصة في الحساب وتحديد وجبات الظهور. إيقاف الصنف يحفظه للتاريخ والمزامنة؛ إزالة المعرفات القديمة مرفوضة.
- الصور الخاصة تحفظ في R2 باسم PHOTOS ومسار معزول لكل حساب، وتُطلب عبر API موثق دون تخزينها في Service Worker. رفع الصورة يحتاج اتصالًا؛ الصور التمثيلية تبقى ضمن الواجهة المخزنة.
- إجماليات عدد الوجبات والإنتاج لكل تاريخ ووجبة في D1، مع مراجعات تمنع الكتابة فوق تعديل آخر. هذه الإجماليات تحتاج اتصالًا في وضع الحساب؛ بيانات النموذج تبقى عند فشل الحفظ.
- التقرير يحسب غرامات الهدر لكل وجبة ونسبة الهدر من الإنتاج فقط للخدمات المسجلة، لكل الأصناف والمراحل ومن القياسات اليدوية المؤكدة. يعرض السجلات المستبعدة ولا يخلط المحاكي أو المعلق. اكتمال تسجيل الهدر والخدمات مسؤولية التشغيل؛ غياب سجل هدر ليس إثباتًا لعدم وجوده.
- ترحيل 0001 يضيف meal_services ولا يعدل بيانات الهدر السابقة. النسخة JSON تشمل الإجماليات ومراجع الصور؛ لا تتضمن ملفات الصور نفسها ولا توفر استعادة تلقائية.

## الإصدار 0.2

- واجهة محطة تسجيل للتابلت والشاشة التفاعلية: تنقل علوي، كتالوج مصور يمينًا ولوحة الوزن والتأكيد يسارًا من عرض 768px، ولوحة أرقام لمس تدعم الكسور والحذف. توزيع أربعة أصناف في الصف من عرض 900px، مع ترتيب عمودي للشاشات الأصغر. زر الحفظ مرتبط بنموذج التسجيل حتى خارج موضعه البصري.
- اختيار الأصناف الثمانية ببطاقات مصورة وأسماء عربية وعلامة اختيار، مع دعم لوحة المفاتيح. الصور التوضيحية مولدة بالذكاء الاصطناعي ومضمنة في `dist/food-images.css` دون طلبات لمواقع صور خارجية، وتدخل في تخزين الواجهة للعمل دون اتصال بعد تحميلها بنجاح.
- صفحة دخول عبر ChatGPT في بيئة Sites، مع تحقق هوية على كل API ومساحة بيانات معزولة لكل حساب.
- تخزين مركزي في D1، وأسعار الأصناف وإعداد اسم المطبخ وحد تنبيه الهدر اليومي.
- تقارير بفترة وصنف ومرحلة ومصدر، وتصفح صفحات، وتصدير CSV آمن من حقن صيغ الجداول، وطباعة كل النتائج أو حفظها PDF من نافذة الطباعة.
- إدخال وزن يدوي من ميزان خارجي، أو محاكي موسوم بوضوح. لوحة الحساب تستبعد سجلات المحاكي.
- قائمة إرسال IndexedDB لكل حساب: تُحفظ قبل مسح المدخلات، مع إعادة محاولة عند عودة الشبكة ودوريًا كل دقيقة أثناء فتح التطبيق. مفتاح السجل الفريد يمنع تكراره عند ضياع استجابة ناجحة.
- نسخ JSON وتنزيل بيانات النسخة القديمة. البيانات القديمة لم تُحذف ولم تُرسل إلى الخادم تلقائيًا.
- وضع تجربة محلي منفصل، لا يجمع كلمات مرور ولا يدعي حماية الحسابات.

## التثبيت والفحص

يتطلب Node.js 22.13 أو أحدث (يفضل 24) لاختبارات SQLite المدمجة.

```sh
npm ci
npm test
npm run build
```

الواجهة المؤلفة موجودة في `dist/`. ينتج البناء Worker مستقلًا في `dist/server/index.js` وملفات ترحيل في `dist/.openai/drizzle/`. المخرجات المولدة مستثناة من Git؛ المصدر والمخطط والترحيلات وملف قفل الاعتمادات مرفوعة.

لمعاينة **وضع التجربة فقط** محليًا، قدم `dist/` بخادم ملفات HTTP. لا تفتح HTML عبر `file://` لأن الواجهة تستخدم JavaScript modules. الخادم الثابت لا يوفر الدخول أو D1؛ ستوضح الصفحة ذلك ويمكن الدخول إلى التجربة.

## التشغيل المستضاف والأمان

يتطلب وضع الحساب نشر Worker خلف **Sites dispatch** مع ربط D1 باسم `DB` وتطبيق ترحيلات `drizzle/` قبل استقبال الطلبات. تكوين هوية الموقع محفوظ في `.openai/hosting.json`، ويظل الموقع الحالي نفسه.

الدخول والخروج يمران بمساري المنصة `/signin-with-chatgpt` و`/signout-with-chatgpt`. يعتمد API على `oai-authenticated-user-id` الذي تزوده المنصة الموثوقة، لا على بيانات يرسلها التطبيق. **لا تنشر Worker مباشرة على عنوان عام يسمح للعميل بتزوير هذه الترويسات.** سياسة إتاحة الموقع الحالية لم تتغير. لا يتضمن هذا الإصدار تسجيلًا عامًا بالبريد وكلمة مرور أو صلاحيات مدير/عامل مشتركة؛ لكل مستخدم سجلاته وإعداداته الخاصة.

### حدود التشغيل دون إنترنت

- تسجيل دخول جديد يحتاج اتصالًا. أثناء جلسة مفتوحة يمكن حفظ قياسات معلقة على الجهاز وإرسالها بعد العودة.
- Service Worker يحاول تخزين الواجهة العامة فقط؛ لا يخزن استجابات API أو بيانات الحساب أو مسارات الدخول. في حال منع المنصة تخزين الواجهة يظل الإدخال في الصفحة المفتوحة ممكنًا.
- IndexedDB قائمة إرسال مؤقتة وليست النسخة المرجعية. البيانات المؤكدة مصدرها D1. حذف بيانات المتصفح يفقد التسجيلات التي لم تُرسل؛ نزّل النسخة الاحتياطية عند الحاجة.
- لا توجد مزامنة في الخلفية بعد إغلاق التطبيق. تعود المزامنة عند فتح الجلسة نفسها.
- آخر سعر محفوظ مركزيًا يُستخدم عند وصول سجل جديد؛ التكلفة قبل التأكيد تقديرية. إعادة إرسال سجل مؤكد لا تغيّر سعره القديم.

### ما لم يتم تفعيله بعد

ربط ميزان حقيقي، إدارة فريق وأدوار داخل المطبخ، والعملاء المتعددون بصلاحيات مشتركة ليست ضمن التنفيذ الحالي. ملاحظات التحسين حسابية وليست تنبؤات ذكاء اصطناعي. الأسعار الافتراضية أمثلة وليست أسعار سوق موثقة.

تغييرات هذا الإصدار تُرفع إلى GitHub؛ نشرها على رابط التطبيق عملية منفصلة. اختبارات الوحدة/تكامل API لا تعني أن تسجيل الدخول أو انقطاع الشبكة قد اختُبرا في متصفح الإنتاج.
